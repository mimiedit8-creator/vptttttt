# VPT Bot — РКЛ-3

Telegram-бот для группы РКЛ-3 Волжского политехнического техникума.

## Возможности
- Расписание: сегодня, завтра, неделя, ручное обновление.
- SQLite-кэш: пользовательские запросы читают сохранённые данные.
- Фоновое обновление расписания.
- Профиль, поиск зарегистрированного пользователя по `@username`.
- Переписка через бота с подтверждением отправки, настройками приватности и блокировкой.
- Сохранение трек-номеров и получение текущего ответа Parcelle по запросу пользователя.

## Запуск на Windows 11
1. Установить Python 3.12+ с https://www.python.org/downloads/windows/ (включить Add Python to PATH).
2. Распаковать проект.
3. Открыть терминал в папке проекта.
4. Выполнить:
   ```powershell
   py -3.12 -m venv .venv
   .venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   Copy-Item .env.example .env
   ```
5. Открыть `.env` и указать `BOT_TOKEN`.
6. Запустить `python -m app`.

Если PowerShell запрещает активацию окружения, не активируйте его: используйте `.venv\Scripts\python.exe -m pip install -r requirements.txt` и `.venv\Scripts\python.exe -m app`.

## GitHub
GitHub Actions здесь предназначен для проверки кода, а не для постоянного размещения Telegram-бота. Бесплатные Actions имеют ограничения по времени выполнения и могут остановить процесс. Для непрерывной работы запускайте бота на включённом ПК или на VPS/платформе для постоянных процессов.

Чтобы GitHub показывал workflow:
- Файл должен лежать строго в `.github/workflows/ci.yml`.
- В репозитории откройте вкладку **Actions**.
- Если workflows отключены, разрешите их в настройках репозитория.

Вкладка Actions запускает проверку Python-проекта. Она не запускает бота 24/7.

## Переменные `.env`
- `BOT_TOKEN` — токен BotFather, обязателен.
- `DATABASE_PATH` — путь к SQLite.
- `SCHEDULE_URL` — прямая ссылка на HTML-страницу/таблицу расписания, если автоматическое определение не подходит.
- `SCHEDULE_REFRESH_MINUTES` — интервал фонового обновления.
- `PARCELLE_API_KEY` — необязательный ключ Parcelle.

## Расписание
По умолчанию бот проверяет страницу студентов ВПТ и ищет HTML-таблицы. Структура сайта может меняться; PDF/XLSX, Google Drive с ограниченным доступом или авторизация требуют отдельного адаптера. Пока данные не удалось достоверно получить, бот сообщает, что расписание недоступно, и не выдумывает пары.

## Посылки
Интеграция использует документированный GET `/tracking/getsync?n=...` и заголовок `X-ApiKey`. Бот показывает поля ответа Parcelle (перевозчик, статус, адрес ПВЗ и срок хранения, если они присутствуют). Автоматические push-уведомления об изменении статуса пока не реализованы. Документация: https://parcelle.ru/dev/.

## Приватность
Получатель должен хотя бы раз запустить бота через `/start`, иначе Telegram не позволит боту начать с ним личный диалог. Никнеймы видны только зарегистрированным пользователям бота. Не публикуйте `.env`, токены и API-ключи.
